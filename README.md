# Madhyapur Thimi Heritage Tour

A digital heritage tourism platform for **Madhyapur Thimi Municipality**, Nepal.
The app maps the **Asta Matrika Heritage Circuit** — the sacred route of the eight
mother goddesses — along with other heritage sites, walking routes, and
tourist amenities.

Built as a **PWA** (Progressive Web App) so visitors can browse offline on their
phones while walking the circuit.

## Frontend setup
```
bash
cd client
npm install
cp .env.example .env
npm run dev
```
